# YARL
Yet Another RTTTL Library

This is a collection of Ringtones written in RTTTL, primarily for use with Meshtastic devices which support the External Notification module such as the WisMesh Tag or Seeed T1000-E. They could also be useful if you happen to stumble back in time to an era where you had a phone that these would be useful for. 

The goal of this repository is to try and make an organized collection of ringtones as I have time to transcribe/create them. High level organization should be from source material (songs,movies,videogames) and lower level organizaion should follow logically. 

Please feel free to add whatever RTTTL ringtones you have. 

## FAQ

### I like a ringtone, but it's too long. 
You can just cut the end off. When writing ringtones to submit into this repository, every effort should be made to create different versions with natural breakpoints like a bar or rest. You know your music best.
